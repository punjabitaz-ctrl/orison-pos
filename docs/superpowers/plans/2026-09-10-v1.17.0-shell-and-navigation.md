# v1.17.0 Shell & Navigation Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the ten-item scrolling tab bar with a three-item bar whose primary control opens one flat grid of every job, and give the app a single header instead of one per screen.

**Architecture:** Both navigations stop being hand-written markup and become renderings of one data model. `nav.js` holds the destination list and two pure selectors over it; `components.js` turns destinations into markup; `app.js` renders the bar, the sidebar and the header from that model and owns the clock. A new `menu` screen renders the same model as a tile grid. Because the model is pure and the markup is a string function, nearly all of this is unit-testable without a browser.

**Tech Stack:** Vanilla ES modules, no build step, no framework, no third-party script (the CSP forbids one). `node:test` + `fake-indexeddb` for units. Google Apps Script backend is **not touched by this release**.

## Global Constraints

Copied from `AGENTS.md` and the spec. Every task's requirements implicitly include these.

- **No build step.** Plain ES modules loaded by `<script type="module">`.
- **No third-party scripts or CDN assets.** `Content-Security-Policy` is `script-src 'self'`.
- **All user-supplied text rendered into the DOM goes through `esc()` from `public/js/ui.js`.** Never `innerHTML` with unescaped data.
- **No comments in client code unless asked.** Existing client modules carry a short block comment at the top saying what the module is for; match that and add nothing more.
- **Money prints through `fmt()`; currency symbols through `currencySymbol()`; note/coin faces through `denomLabel()`.** Never hard-code a symbol or a denomination.
- **Touch targets ≥ 44px.**
- **A new screen must be registered in three places or the offline shell breaks:** `SCREENS` in `public/js/app.js`, the role-restriction list, and `SHELL` in `public/sw.js`.
- **Release protocol (`AGENTS.md`) is mandatory:** in the *same commit* — `public/sw.js` `VERSION` → `orison-pos-v1.17.0`, `package.json` + `package-lock.json` version → `1.17.0`, `CHANGELOG.md`, `RELEASE_NOTES.md`, `HANDOVER.md`, and any of `README.md` / `AGENTS.md` / `SECURITY.md` / `backend/README.md` the change affects. Then `git tag v1.17.0` and `git push origin main --tags`.
- **Validation gates, all green before any commit:** `node tests/backend-sim.mjs` (expect **PASS 446 FAIL 0** — unchanged, this release does not touch the backend), `npm run test:client`, `node --check` on every touched client file, `node tests/pdf-send-smoke.mjs` (expect **PASS 19 FAIL 0**).
- **Baseline at start:** v1.16.0, backend-sim 446, client units 237.

## Scope notes

Two deliberate departures from the spec text, both to be recorded in the release notes:

1. **`primaryTabs()` lives in `nav.js`, not `app.js`.** `app.js` calls `boot()` at import time, so a test importing it would boot the whole application. A pure module is the only way the spec's "unit-testable without a DOM" is actually true.
2. **The launcher ships 10 tiles this release, not 13.** Cash Pick Up and Employee Expense do not exist until v1.19.0 creates their transaction kinds, and Shift keeps its Dashboard card until v1.19.0 extracts the shift dialogs. No tile is shipped that does not do what its label says.

```javascript
'use strict';

/* The navigation model: one list of destinations, and the selectors the bar,
   the sidebar and the launcher all read. Pure — no DOM, no imports — so the
   shape of the app's navigation can be tested without a browser. */

const MANAGER = ['admin', 'manager'];

export const DESTINATIONS = [
  { id: 'refund', label: 'Refund', screen: 'history', roles: MANAGER },
  { id: 'payout', label: 'Paid Out', screen: 'dashboard', roles: MANAGER, dialog: 'payout' },
  { id: 'staff', label: 'Time Clock', screen: 'staff', roles: null },
  { id: 'customers', label: 'Customers', screen: 'customers', roles: MANAGER },
  { id: 'inventory', label: 'Products', screen: 'inventory', roles: MANAGER },
  { id: 'alerts', label: 'Alerts', screen: 'alerts', roles: MANAGER },
  { id: 'purchases', label: 'Purchases', screen: 'purchases', roles: MANAGER },
  { id: 'reports', label: 'Reports', screen: 'reports', roles: MANAGER },
  { id: 'dashboard', label: 'Dashboard', screen: 'dashboard', roles: null },
  { id: 'settings', label: 'Settings', screen: 'settings', roles: null },
];

const BAR = [
  { id: 'menu', label: 'Menu', screen: 'menu', primary: true },
  { id: 'register', label: 'Sell', screen: 'register', primary: false },
  { id: 'history', label: 'History', screen: 'history', primary: false },
];

function allows(roles, role) {
  if (!roles) return true;
  return roles.indexOf(String(role || 'cashier')) >= 0;
}

export function primaryTabs() {
  return BAR.map((t) => ({ ...t }));
}

export function menuTiles(role) {
  return DESTINATIONS.filter((d) => allows(d.roles, role)).map((d) => ({ ...d }));
}

export function isRestricted(id, role) {
  const hit = DESTINATIONS.find((d) => d.id === id);
  if (!hit) return false;
  return !allows(hit.roles, role);
}
```

```javascript
'use strict';

/* The launcher: every job this account can do, as one flat grid of labelled
   tiles. No groups, no submenus - the whole point is that nothing here has to
   be learned or remembered. */

import { esc } from '../ui.js';
import { menuTiles } from '../nav.js';
import { tileGrid } from '../components.js';
import { openPayoutDialog } from '../money-dialogs.js';

export const screen = {
  id: 'menu',
  tab: 'menu',
  title: 'Menu',

  async render(ctx, root) {
    document.getElementById('tabbar').classList.remove('hidden');
    const { state, router } = ctx;
    const role = (state.user || {}).role || 'cashier';
    const tiles = menuTiles(role);

    root.innerHTML = `
      <header class="scr-head">
        <div class="scr-title">
          <h2>Menu</h2>
          <p>${esc(String(role))}</p>
        </div>
      </header>
      ${tileGrid(tiles)}`;

    const onTap = async (e) => {
      const btn = e.target.closest('[data-go]');
```

```javascript
/* Money-out dialogs, extracted from the dashboard so the launcher can open
   them directly. */

import { esc, toast, openModal, closeModal, currencySymbol } from './ui.js';
import { createPayout } from './money.js';

export function openPayoutDialog(ctx, onDone) {
  const user = (ctx && ctx.state && ctx.state.user) || {};
  const modalEl = openModal(`
    <div class="tx-detail payout-modal">
      <button class="icon-btn abs-close" data-x>✕</button>
      <h3>Record paid out</h3>
      <p class="muted">Cash leaving the business — vendor payment, cash pick-up, expense. Managers and admins only.</p>
      <label class="field-label">To / reason
        <input class="field" id="po-to" placeholder="e.g. Vendor, cash pick-up">
      </label>
      <label class="field-label">Amount (${esc(currencySymbol())})
        <input class="field" id="po-amt" type="number" min="0" step="0.01" placeholder="0.00">
      </label>
      <label class="field-label">Note (optional)
        <input class="field" id="po-note" placeholder="e.g. restock — keyboards">
      </label>
      <button class="btn" id="po-confirm" style="--bg:#c62828">Confirm paid out</button>
    </div>`);
  modalEl.querySelector('[data-x]').addEventListener('click', closeModal);
  const confirm = modalEl.querySelector('#po-confirm');
  confirm.addEventListener('click', async () => {
    const amount = Number(modalEl.querySelector('#po-amt').value);
    if (!(amount > 0)) { toast('Enter an amount', 'warn'); return; }
    confirm.disabled = true;
    try {
      await createPayout({
        counterparty: modalEl.querySelector('#po-to').value.trim(),
        grandTotal: amount,
        note: modalEl.querySelector('#po-note').value.trim(),
        user,
      });
      closeModal();
      toast('Paid out queued', 'ok', 1800);
      if (onDone) await onDone();
    } catch (_) {
      confirm.disabled = false;
      toast('Failed — try again', 'warn', 2400);
    }
  });
  return modalEl;
}
```
